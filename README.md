
# 🚌 Transit Carbon Calculator

An interactive tool showing how much CO₂ you save by choosing
transit over driving. Built with plain HTML/CSS/JS, no frameworks needed.

🌐 Live tool: https://meyeringn.github.io/transit-carbon-calculator

Data sources: EPA GHG emission factors, APTA transit emissions research.
Built June 2026 as part of Nico's civic tech portfolio.
